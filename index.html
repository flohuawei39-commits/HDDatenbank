Sicherung

        

          Der gesamte Bestand als eine Datei, unverschlüsselt und lesbar. Gedacht
          zum Umziehen auf ein anderes Gerät und als Rückweg, falls einmal etwas schiefgeht.
          Die Datei gehört nicht in eine Cloud und nicht in ein Repository.
        

        

          
          
          
        

        

        

          Ausgelieferte Fassung: —. Steht hier nach einer
          Veröffentlichung noch die alte Kennung, hält der Browser die alten Dateien fest —
          Seite hart neu laden oder ein paar Minuten warten.
        

      


      

        
Abgleich mit GitHub

        

          Ohne Abgleich liegen die Daten nur in diesem Browser. Mit Abgleich landen sie
          verschlüsselt in einem privaten Repository und stehen auf jedem Gerät
          zur Verfügung, auf dem du Passwort und Zugriffsschlüssel einträgst. GitHub sieht dabei
          nur Kauderwelsch.
        

        

          Der Zugriffsschlüssel ist ein fein abgestufter Token, der genau ein Recht braucht:
          Contents: Read and write auf dieses eine Repository. Das Repository muss
          privat sein.
        

        

          
          
        

        

          
          
          
        

        

          
          Wird gebraucht, um vor dem ersten Schreiben nachzusehen,
            ob im Repository schon ein Bestand liegt — und ob er zu diesem Passwort gehört.
